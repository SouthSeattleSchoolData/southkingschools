Update the school data

Downloads the latest OSPI Report Card files from data.wa.gov and rebuilds data/schools.json. OSPI usually publishes a new school year's files in the fall.

  1. Enter the school year and click Build data. It takes about a minute.
  2. Check the summary, then click Download schools.json.
  3. Replace data/schools.json in the GitHub repository with the downloaded file and commit.

Format: 2025-26. If a year's files can't be found by name, add their IDs to tools/config.js.
